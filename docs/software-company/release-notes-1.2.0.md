# OurFreeModel Standalone（our-free-model-standalone）1.2.0

## ⚠️ 先读：本版本有破坏性变更

**管理台精简为六页**。如果你在用 1.1.0 的完整页面模式，请先看下面的迁移对照：

- **保留的六页**：账号渠道、智能调度、网关与 API 接入、用量日历、请求日志、服务设置。
- **移除的页面**：概览、模型工作台、客户端与订阅、模型与开关、用量统计、资源库、聚合渠道、路由组、EAC 协付渠道、赞助、应用更新；同时移除启动参数 `--full`（不再有精简/完整两种模式，打开即是完整产品）。
- **功能去哪了**：
  - 模型启停 → 智能调度页，候选清单内每个模型可直接开关；
  - 用量统计 → 用量日历（按日查看各模型 token 消耗与积分领取）；
  - 网关端口、API 密钥、主题等配置 → 服务设置页。
- **API 网关完全不受影响**：Base URL、API Key、模型名的客户端配置无需任何改动，`model=auto` 与直连具体模型的行为与之前一致。
- **关于 1.1.0**：其发布不足一日且尚无下载记录，直接由本版本取代；如你已安装 1.1.0，直接升级到 1.2.0 即可。

## 界面全面换新
- 双主题重新设计：浅色主题为暖色纸面，深色主题为暖调深色；两套主题共用同一套布局与组件，仅深浅不同，切换无违和。
- 统一的圆角卡片、更轻的字重；主色调为暖中性色，绿色只出现在按钮、开关与状态标识上，界面更安静。
- 账号渠道页（日常主页面）逐组件精修：渠道卡、徽章、统计行、签到开关与页头全部换新。

## 默认一级入口：智能调度与用量日历
- **智能调度**：勾选渠道模型、排定优先顺序，之后所有客户端只需 `model=auto`——网关按你的顺序调用第一个可用模型，某模型当日配额耗尽自动落到下一个；调度池全部耗尽时返回 429 并附各模型解禁时间。
- **用量日历**：月视图逐日查看各模型 token 消耗与完成领取的渠道数，悬停看明细、点击看全天详情。

## 升级
```
npm i -g our-free-model-standalone@1.2.0
```
或免安装直接体验：`npx our-free-model-standalone`（安装后也可用短命令 `ofm`）。需要 Node.js 22.19.0+ 或 24.0.0+，零运行时依赖。
