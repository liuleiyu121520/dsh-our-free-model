# OurFreeModel Standalone（our-free-model-standalone）1.2.1

1.2.0 的验收修复版，无破坏性变更。升级：

```
npm i -g our-free-model-standalone@1.2.1
```

需要 Node.js 22.19.0+ 或 24.0.0+，零运行时依赖。

## 本机免登录修复
- 服务重启或升级后，浏览器里遗留的旧会话不再把你锁在登录页：本机直接打开管理台即可进入控制台。
- 主动退出登录、轮换 API Key 后仍会要求重新登录，安全语义不变。

## 图片消息自动选视觉模型
- `model=auto` 且消息包含图片时，只在调度池中「支持视觉」的模型之间接力，不会再把图片发给纯文本模型。
- 调度池里没有支持视觉的模型时，会返回明确的错误指引（提示到智能调度页添加视觉模型），而不是含糊失败。纯文本请求的调度行为完全不变。

## 智能调度页改进
- 候选列表默认隐藏「已停用」和「无可用账号」的模型，各配一个显示开关，需要时打开即可找到并重新启用。
- 独立的池状态区移除，改为池内每行直接显示「已消耗 M/N（账号）」；某模型当日账号全部耗尽时，行内同时给出最早的解禁时间。
- 页面本身不再出现纵向滚动条：候选与池列表在各自的卡片内滚动，一屏即可看全两区；保存成功改为轻提示、自动消失。

## 界面修正
- 按钮悬停对比度达标；筛选与接入页的输入框改为单层样式；接入页与设置页在 1440 宽度下对齐；模型下拉菜单的层叠显示修复；渠道页页头精简。

## 其他
- 页面切换同步到地址栏：刷新或分享链接后停留在当前页，不再回到默认页。
- 说明：积分自动签到随服务进程运行——启动约 30 秒后进行第一轮，之后每小时检查一次；它与网页里的开关状态无关。

## 兼容性
- 无破坏性变更：客户端配置（Base URL / API Key / 模型名）无需任何改动；直连具体模型与 `model=auto` 纯文本请求的行为与 1.2.0 一致。
