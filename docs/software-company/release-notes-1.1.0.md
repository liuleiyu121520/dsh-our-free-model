# OurFreeModel Standalone（our-free-model-standalone）1.1.0

**升级**：`npm i -g our-free-model-standalone`（需要 Node.js ^22.19.0 或 ≥ 24.0.0；零运行时依赖）。
**首次体验**：`npx our-free-model-standalone`，或安装后使用短命令 `ofm`。

## 全新外观
- 全站界面换新：暖中性底色、活力绿主色、更柔和的圆角与更轻的字重；昼/夜双主题同步换新，主题切换动效保留。
- 16 个页面全部经过系统性的界面终审与精修（含无障碍、响应式与动效降级检查）。

## 智能调度（新）
- 新增「智能调度」页：勾选渠道模型加入调度池，拖拽或按钮调整优先顺序；配置保存在本机，重启不丢。
- 对外只需一个模型名：`model=auto`（别名 `ourfreemodel`）。网关按你的顺序优先调用第一个可用模型，模型内部的多账号轮换规则不变；某模型当日配额全部耗尽后自动落到下一个，且当天不再重复尝试已耗尽的模型。
- 调度池全部耗尽时返回 429，并在响应中附上每个模型的解禁时间，方便客户端实现退避重试。
- `GET /v1/models` 现已包含 `auto` 条目；「API 接入」页新增说明与一键复制的调用示例。

## 用量日历（新）
- 新增月视图日历：每格显示当日各模型 token 消耗与完成领取的渠道数；悬停查看明细卡片，点击打开全天详情。
- 积分领取历史自本版本开始记录（手动领取与自动签到均包含）；此前的日期会如实标注「无数据」，不会显示成 0。

## 兼容性
- 无破坏性变更：现有客户端配置（Base URL / API Key / 具体模型名）无需任何改动；直连具体模型的行为与 1.0.2 一致（发布前已通过全量回归测试）。

## 关于独立版与 DSH 插件版
- 自 1.1.0 起，本 npm 包（OurFreeModel Standalone）与 DSH 插件版是两个独立产品：本包只包含独立本地服务所需的代码；DSH 插件继续按其原有渠道发布，不受本版本影响。
